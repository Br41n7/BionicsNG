# Hardware Research

This directory is for documented hardware concepts, requirements, designs, test plans, and results.

## Maturity labels

Every design or result should be labelled accurately, for example:

- Concept only.
- CAD/modelled.
- Simulated.
- Fabricated.
- Bench-tested (include the test).
- Independently reviewed.
- Validated for a specifically defined intended use (requires appropriate evidence and oversight).

Do not use “clinically validated” or “patient-ready” unless the evidence genuinely supports that claim and applicable requirements have been met.

## Minimum documentation

For each design, include intended purpose, requirements, bill of materials, material specifications, assembly notes, electrical/mechanical interfaces, test methods, hazards and mitigations, failures, results, limitations, version, and source files where licensing permits.

No human use or testing should be performed merely because a design is published here. See `documentation/safety-and-ethics.md`.
