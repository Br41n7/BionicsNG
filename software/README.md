# Software and Simulation

This directory is intended for software, embedded-control research, data analysis, and simulation supporting the project.

Possible future work includes offline analysis of public or synthetic EMG-like signals, control-system simulation, component-cost analysis, and tools for maintaining the localization evidence register.

## Requirements for contributions

- State the language, dependencies, runtime, and how to reproduce results.
- Use synthetic or appropriately licensed data by default.
- Never commit secrets, credentials, private patient data, or proprietary source code without permission.
- Document assumptions, limitations, and test coverage.
- Do not imply that simulation proves hardware safety or clinical performance.
- Identify any code that controls actuators and document safe test conditions before running it on hardware.

No production-ready or clinically validated control software is claimed at this stage.
