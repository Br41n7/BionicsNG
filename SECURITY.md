# Security Policy

BionicsNG welcomes responsible reporting of security issues in project code, build instructions, digital infrastructure, and published technical materials.

## Reporting a concern

Please do not publish exploitable details, credentials, private data, or instructions that would endanger people in a public issue. Contact the repository maintainers privately using a contact method listed on the GitHub profile. Include:

- A concise description of the issue and its potential impact.
- Affected file, version, commit, or service, if known.
- Reproduction steps that are safe and lawful.
- Any suggested mitigation.

Do not test against systems you do not own or have explicit authorization to assess. Do not include patient information or other sensitive personal data.

## Scope and response

This project is early-stage and may not yet operate a production service. Maintainers will acknowledge reports when reasonably possible, assess severity, and coordinate any public disclosure after a fix or mitigation is available. No response-time guarantee is currently offered.

## Safety-critical designs

If a report concerns a hardware design that could injure a person, clearly explain the failure mode and test conditions. Do not assume that a software security review establishes medical-device safety.
