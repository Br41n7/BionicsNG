# Research

This directory contains evidence-backed research about the Nigerian prosthetics/bionics ecosystem, relevant materials and manufacturing processes, component localization, and technical literature.

## Research rules

- Follow `../documentation/research-methodology.md`.
- Cite the source for every material factual claim.
- Label claims Verified, Reported, Hypothesis, or Unknown.
- Record source dates and limitations.
- Distinguish local design, assembly, fabrication, component manufacture, and raw-material processing.
- Treat promotional claims as leads unless capability is independently substantiated.
